# GitHub Rock Backend Data

Data pipeline and offline cache for **GitHub Rock**.

This repository follows the backend-data pattern used by Komi Store's knowledge-base pipeline, adapted for GitHub Rock.

## Included options

- **Trending**
- **New Releases**
- **Most Popular**
- **Topics:** Privacy, Media, Productivity, Networking, Dev Tools
- **Platforms:** Android, Windows, macOS, Linux
- **Offline feed:** all, Android, Windows, macOS, Linux

Generated structure:

```text
cached-data/
├── feed/
├── trending/
├── new-releases/
├── most-popular/
└── topics/
    ├── privacy/
    ├── media/
    ├── productivity/
    ├── networking/
    └── dev-tools/
```

Each generated JSON file uses a stable envelope containing `category`, `platform`, `lastUpdated`, `totalCount`, and `repositories`.

## Real GitHub data

`scripts/fetch_all_categories.py` discovers real repositories, verifies platform-specific release assets, filters inappropriate repositories, and generates the category caches.

Supported installers:

| Platform | Formats |
|---|---|
| Android | APK |
| Windows | EXE, MSI |
| macOS | DMG, PKG |
| Linux | AppImage, DEB, RPM, PKG.TAR.ZST |

Android APK detection explicitly avoids Alpine Linux `.apk` packages.

No fake repositories or placeholder catalog data is committed. Cache files are generated by GitHub Actions after credentials are configured.

## Authentication

Supported GitHub Actions secrets:

- `GH_TOKEN_TRENDING`
- `GH_TOKEN_NEW_RELEASES`
- `GH_TOKEN_MOST_POPULAR`
- `GH_TOKEN_TOPICS`
- `GITHUB_TOKEN` as fallback

Optional integrations:

- `DATABASE_URL` — PostgreSQL persistence
- `MEILI_URL` / `MEILI_MASTER_KEY` — Meilisearch indexing

Secrets are never stored in this repository.

## Feed cache

The offline feed publisher mirrors:

`https://github-rock-backend.onrender.com/v1/feed`

Override the origin with `FEED_BACKEND_ORIGIN`.

## GitHub Actions

- **Fetch All Repository Categories** — daily at 02:00 UTC and manually.
- **Publish Feed Offline Cache** — every 3 hours and manually.

The category workflow validates generated JSON before committing it.

## Local usage

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r scripts/requirements.txt

GITHUB_TOKEN=ghp_... python scripts/fetch_all_categories.py
```
